# uni-app开发仓库管理小程序

源码地址：ym7k.com/17777/

传统仓库管理大多依赖电脑端管理系统或者纸质台账，库管人员出入库登记、盘点货物时，需要来回切换设备，操作不够便捷。基于 UniApp 开发的仓库管理小程序，打通移动端操作与后台数据管理，一套前端代码可以适配微信小程序，搭配后端服务使用，让仓库管理人员在现场随时完成货品操作，实现仓储业务轻量化线上管理。

小程序面向仓库管理员、入库员、领料人员等使用者设计，核心围绕货品档案、出入库、库存盘点、单据查询几个核心业务搭建。用户通过账号密码或者授权登录进入系统，不同岗位分配对应权限，普通领料人员只能提交领料申请，库管员拥有审核、录入库存的权限，避免无关人员随意修改库存数据。

货品档案是整个系统的基础模块，管理人员可以在小程序端新增商品信息，录入货品名称、分类、规格型号、单位、存放库区、货架编号、安全库存等信息，支持上传货品图片，方便识别。所有货品支持分类管理，后续出入库时可以快速检索选择。系统支持多仓库、多货架管理，如果企业有多个仓储点位，可以自由切换仓库查看库存。

出入库是小程序高频使用功能。入库场景包含采购入库、退货入库，填写货品、数量、存放位置，提交生成入库单；出库支持销售出库、领料出库、调拨出库，填写出库货品与数量。提交单据之后，单据状态实时更新，相关人员可以在线审核。所有出入库记录自动留存，每一笔库存变动都有源单据可查，形成完整库存流水。库存调拨功能支持货品在不同仓库、不同货架之间转移，同步更新两边库存数量。



库存盘点模块解决线下盘点难题。库管员在仓库现场可以直接打开小程序，按分类或者货架生成盘点清单，对照实物录入实际盘点数量，系统自动对比账面库存，生成盘盈、盘亏记录，提交盘点单留存记录，不用再手写盘点表回去录入电脑，大幅提升盘点效率。

查询与统计功能方便随时掌握仓储情况。用户可以根据货品名称、单据类型、时间范围检索出入库单据，查看单据详情。库存查询页面实时展示当前库存数量，当货品数量低于设置的安全库存时，系统给出预警提醒，及时提醒补货。小程序内自带简易数据看板，展示入库总量、出库总量、库存预警商品等信息。

配套的管理后台负责基础配置、权限管理与数据汇总。管理员维护货品分类、仓库货架信息，分配账号权限，查看全部单据流水，导出库存报表、出入库报表，方便财务和管理人员对账。

UniApp 的优势在于移动端体验流畅，部署成本低，不用单独安装 APP，微信扫码即可使用。适合中小型工厂、门店、耗材仓库使用，不需要投入昂贵的大型仓储系统。同时代码具备可扩展性，后续可以根据需求增加条码扫码录入、供应商管理等功能。

这套小程序把仓库管理从固定电脑端解放出来，让库管人员在货架旁完成登记、盘点、查库存，减少台账出错，提升仓库日常作业效率，是中小仓储场景高性价比的数字化方案。
